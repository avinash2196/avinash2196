## Prompt-Driven Development

I am documenting an engineering workflow for using AI coding assistants without giving up architectural discipline or human accountability.

The workflow follows:

**Requirements → Plan → Human Review → Implementation Plan → Human Review → RED Tests → GREEN Code → Refactor → Final Review**

The goal is not simply to generate code faster. It is to make AI-assisted changes:

* easier to review
* aligned with requirements
* supported by tests
* traceable to engineering decisions
* maintainable as the repository evolves
